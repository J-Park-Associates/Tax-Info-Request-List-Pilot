Tax Document Tracker
Marketing Demo

Presenter Guide

Full script: DEMO-SCRIPT.md in the project folder.

1 Set the scene

"Every tax season starts the same way: we send you a list of documents we need, and then everyone spends February playing email ping-pong. We replaced that with a shared folder that checks the documents itself."

Click Reset Demo so every request shows Missing.

2 Pick the return type

"Setting up a new client takes a minute, not a morning. The first question is simply: what kind of return? Each form type carries its own tailored request list — a 1040 asks for W-2s and 1098s, an 1120-S asks for the trial balance and shareholder basis."

Click New Engagement. Show the form-type cards — 1040, 1120, 1120-S, 1065, 1041, 990 — then pick Form 1040.

3 Build the tailored list

"Here's the 1040 checklist from years of engagements — I tick what applies to your situation, add anything unusual, and everything behind the scenes builds itself. Note the keyword column: that's what lets us recognise each document later, and it's yours to edit."

Name it after the prospect's own family or company. Untick a couple of items, add one custom request (e.g. "Rental Property Records"). Click Create Engagement — the request list, the client's folder and our working tree are all built from that one click.

4 What the client sees

"Here's the part clients actually care about. They get one folder. Not a folder per document, not a portal with a password — one folder, and the instruction is 'drop everything in here.' They never sort anything, name anything, or work out which file matches which line on our list."

Click Open Client Folder. Show how little is in it: _README.txt and PBC.

5 Play the client

"Let's be the client — helpful, busy, occasionally wrong. Everything goes in the one folder, including last year's W-2 by mistake, the same W-2 twice, a Word file where we need the 1098, and a vacation photo."

Click Open Sample Documents, select them all, and drag them into the one client folder. No sorting — that's the whole point.

6 The moment — scan

"In production this runs by itself every fifteen minutes. Watch it sort that pile — without any person opening a single file."

Click Run Scan. Then re-open Client folder: the drop zone is empty and every original is sitting in PBC under its own name. Walk the results: A01 Received — both 2025 W-2s found and renamed, the duplicate kept but filed once. A02 Partial — 2 of 3, it knows exactly what's still owed. Needs review — last year's W-2 ("looks like A01 but the period is wrong"), the Word file, the Google Sheets shortcut and the photo. It never guessed.

7 The accountant's view

"And it all lands in the tool accountants already live in — Excel. One sheet for where each request stands, and one that maps every file the client sent to exactly where it ended up and what we renamed it to. Nothing disappears into a black box."

Click Open Manifest in Excel, then show _index.xlsx — original name, filed-as name, and the reason for anything in review.

8 The trust close

"Three guarantees. Every decision is a deterministic rule — no AI ever reads your tax documents. Your originals are never altered: we move them into PBC byte for byte under your own file names, we work from copies, and every move is written down. And your judgment always wins — one column in Excel overrides any automated result."

Point at the assurance bar at the bottom of this screen.
