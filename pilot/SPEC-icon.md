## Questions for Jason (answer before the build)

   Start menu still say "Tax Document Tracker Pilot" (`app/package.json`

## What changes

| # | Where it is seen | File | Change |
|---|---|---|---|
| 1 | The program file, its desktop and Start menu shortcuts, the taskbar, Alt+Tab | `Build App.bat` (the `electron-packager` line, about line 66) | Copy `pilot/brand/tax-document-console/app/icon.ico` to `app/assets/icon.ico` and add `--icon=assets\icon.ico` to the packager command. electron-packager writes it into the .exe |
